# ai_generated

Machine-written exhaustive coverage — a regression net, not required reading: date and
time parsing tables, business-hours internals, the Google Calendar adapter against a
stub client, SQLite round-trips, URL encoding, tool-schema introspection, HTML escaping,
and every individual branch of the confirmation text and the 404 page.

The guarantees worth a human's attention are the dozen tests one directory up. These run
by default and must stay green; fixtures come from `tests/conftest.py` and the scripted
model from `tests/fakes.py`.
